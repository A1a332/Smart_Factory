# Smart Factory

Satisfactory（幸福工厂）SML 模组，提供枢纽/建筑一键传送、MOD 建筑分组汉化、收集品追踪等功能。

## 源码说明
本仓库**不包含源代码**（源码不公开）。模组以编译后的发布包形式提供，请见右侧 **Releases**。

## 安装
- **推荐（SMM）**：在 Satisfactory Mod Manager 中搜索 `Smart Factory` 安装，依赖库 `SmartFactoryLib` 会自动拉取。
- **手动**：解压 `Smart_Factory-v1.0.0.zip` 到游戏 `FactoryGame/Mods/` 目录；若未使用 SMM，还需把 `SmartFactoryLib-v1.0.0.zip` 也解压到同一 `Mods/` 目录。

## 版本
当前正式版：**v1.0.0**（Steam 目标构建，BuildId 513885）。
